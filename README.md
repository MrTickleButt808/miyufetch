# miyufetch

A Python system information fetch utility with optional character artwork.

## Features
- OS, kernel, CPU and GPU information
- Memory, disk, battery and display details
- Desktop environment and theme information
- Terminal color palette
- Kitty image display and Chafa fallback

## Run from source

    python miyufetch.py

## Arch Linux

The planned AUR package will be named `miyufetch-git`.
